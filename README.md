# synchronny_RL-project

models folder - some Ufactory Lite 6 model files essential for the pybulltet simulation. The files were taken from the oficial Ufactory git repo and converted to the necessary file formats

ros_ws - Folder with the ros workspace used in the pc running the ros nodes


env_train.py - trainning script 

evaluate_trainning.py - evaluation script with visual pybullet simulation

real_robot_control_mocap.py - final script for controling the robot acording to the RL model while having the object position from the real optitrack mocap system

real_robot_control.py - old script for controling the robot acording to the RL model but without real object data
